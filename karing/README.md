# Конфиг Karing: hysteria2 + российский трафик мимо туннеля

`karing-hysteria2-ru-direct.json` — профиль sing-box для Karing. Весь трафик идёт
через hysteria2, **кроме** российского: он идёт напрямую, с домашнего IP.

Так Госуслуги, MAX, банковские приложения, Ozon/WB, Яндекс и любые сайты в зоне
`.ru` видят настоящий российский адрес и не блокируют вход. Всё остальное —
через сервер.

## 1. Подставить четыре значения

В файле есть четыре плейсхолдера:

| Плейсхолдер     | Что это                                  |
|-----------------|------------------------------------------|
| `__SERVER__`    | адрес VPN-сервера (IP или домен)         |
| `443`           | порт hysteria2 (`server_port`)           |
| `__PASSWORD__`  | пароль hysteria2                         |
| `__SNI__`       | имя из TLS-сертификата (`tls.server_name`)|

`__SERVER__` встречается дважды: в `outbounds` и в первом правиле `dns.rules` —
второе нужно, чтобы имя сервера резолвилось напрямую, а не через сам туннель.
Если сервер задан голым IP, это правило можно удалить.

### Откуда взять значения

**Проще всего — из рабочей ссылки `hy2://`**, которая уже стоит в текущем клиенте:

```
hy2://ПАРОЛЬ@ХОСТ:ПОРТ/?sni=ИМЯ&insecure=0#Название
```

- `ПАРОЛЬ` → `password`
- `ХОСТ` → `server` (и `dns.rules[0].domain`)
- `ПОРТ` → `server_port`
- `sni=` → `tls.server_name`
- `insecure=1` → поставить `"insecure": true`

**Либо с сервера** — в конфиге hysteria (`/etc/hysteria/config.yaml` или рядом с
docker-compose): пароль лежит в `auth.password`, порт — в `listen`, домен — в
`acme.domains` или `tls.cert`.

### Если у сервера самоподписанный сертификат

```json
"tls": { "enabled": true, "server_name": "любое.имя", "insecure": true, "alpn": ["h3"] }
```

### Если включён обфускатор Salamander

Добавить в outbound `proxy`:

```json
"obfs": { "type": "salamander", "password": "ОБФУС-ПАРОЛЬ" }
```

### Если включён port hopping

Вместо `server_port` использовать диапазон:

```json
"server_ports": ["20000:50000"], "hop_interval": "30s"
```

## 2. Импорт в Karing

1. Сохранить заполненный файл как `.json` (например, `vpn.json`).
2. Karing → **Профили** → **+** → **Импорт из файла** → выбрать `vpn.json`.
   На телефоне — сначала положить файл в «Файлы»/«Загрузки».
3. Выбрать профиль и включить VPN.

Заполненный файл содержит пароль от сервера — **не коммитить его сюда**,
репозиторий публичный. `.gitignore` уже блокирует `*-filled.json` и `*-real.json`.

## 3. Как устроена маршрутизация

Правила проверяются сверху вниз, первое совпавшее выигрывает.

| Что                                                                     | Куда     |
|-------------------------------------------------------------------------|----------|
| DNS-запросы                                                              | перехват |
| приватные адреса (`192.168.*`, `10.*`, …)                                | direct   |
| `.ru`, `.su`, `.рф`, `.moscow`, `.tatar`, `.дети`                        | direct   |
| ~90 доменов российских сервисов не в зоне `.ru` (VK, MAX, Сбер, Т-Банк, Ozon, WB, Авито, Яндекс, Кинопоиск, habr, 2ГИС…) | direct |
| geosite `category-ru` — большой список российских доменов                | direct   |
| geoip `ru` — ~5000 российских IP-диапазонов, ловит подключения по голому IP | direct |
| всё остальное                                                            | proxy    |

DNS разделён так же: российские имена резолвит Яндекс DNS напрямую (правильные
российские CDN-адреса), остальное — Cloudflare DoH через туннель, без утечки
запросов провайдеру.

geoip-правило важно отдельно: банковские приложения часто ходят на IP без
доменного имени, и только по IP их можно оставить в прямом канале.

Списки `category-ru` и `geoip ru` скачиваются с
[KaringX/karing-ruleset](https://github.com/KaringX/karing-ruleset) через туннель
и обновляются раз в неделю. Если скачать не удалось, встроенные списки доменов
продолжают работать.

## 4. Проверка

- Открыть 2ip.ru — должен показать российский адрес и провайдера.
- Открыть любой зарубежный сервис проверки IP — должен показать адрес сервера.
- Зайти в Госуслуги и в банковское приложение — должны пускать как без VPN.

В Karing на экране соединений видно, какое правило сработало для каждого запроса,
— это самый быстрый способ понять, почему сайт пошёл не туда.

## 5. Добавить своё исключение

Домен, который должен ходить напрямую, дописать в **два** места: в
`route.rules` (нужный блок `domain_suffix`) и в такой же блок в `dns.rules`.
Только в маршрутизации — недостаточно: имя всё равно будет резолвиться через
зарубежный DNS и вернёт неподходящий адрес.

## Совместимость

Профиль рассчитан на sing-box 1.11–1.13: правила-действия (`hijack-dns`) вместо
устаревших выходов `block`/`dns`, удалённых в 1.13, и классический формат
`dns.servers`, который убирают только в 1.14.
